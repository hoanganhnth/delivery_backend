# Historical documentation archive

This folder is reserved for documents that are useful for provenance but no
longer describe the current system. Archived material must carry a
`Historical/Superseded` banner and link to its current replacement.

Active product, architecture, API, security and operations truth belongs under
`docs/platform/system/`, `docs/platform/product/` or the owning backend/client
documentation folders. Plans and learning notes remain historical working
memory and are not indexed as public handbook truth.
